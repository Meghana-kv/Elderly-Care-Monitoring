# Elderly Care Monitoring — Case 61
Educational simulation only. No actual caregiver notifications or clinical fall detection. Data is synthetic and in-memory. Run `python app.py`, open http://127.0.0.1:5001, then use another terminal for `python -m pytest -v --cov=alert_service --cov-report=term-missing`, `python demo.py`, and `python monitor.py`. The monitor takes ten minutes. No authentication or persistence; do not expose publicly.
